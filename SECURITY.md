# Security Policy

## Supported Versions

Only the latest production version of this software is supported with security updates. Older versions and development branches may not receive security fixes.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately by email to **support@ridebangla.bd**. Do **not** open a public issue for a security problem.

Please include as much detail as possible: the affected component, the steps to reproduce the issue, and its potential impact. The Ride Bangla team will acknowledge the report, investigate it, and coordinate any public disclosure after a fix is in place.

Thank you for helping keep Ride Bangla and its users safe.

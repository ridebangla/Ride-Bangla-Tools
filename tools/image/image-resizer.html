How to use Image Resizer

  1. Upload your photo, or tap a quick preset like "ID / NID / Facebook (1500×1000)".
  2. Check the width and height fields — turn off "Lock aspect ratio" if you need an exact size.
  3. Pick how to handle the mismatch: Crop to fill (recommended), Stretch, or Fit inside.
  4. Click Resize, then download — the exact pixel size is shown above the download button.

Frequently asked questions

Is Image Resizer free to use?

Yes. Image Resizer is completely free, with no sign-up, no daily limit, and no watermark on what you download.

Is my photo uploaded to a server?

No. Image Resizer runs entirely in your browser using JavaScript — your photo never leaves your device.

How do I meet a minimum size like 1500 x 1000 pixels for an ID verification upload?

Enter the required width and height, use the ID / NID / Facebook preset for a shortcut, and keep "Crop to fill" mode selected so both dimensions are met exactly without stretching or distorting the photo.

Will resizing distort or stretch my photo?

Only if you choose "Stretch" mode. The default "Crop to fill" mode keeps the photo's proportions correct and simply trims the extra edges, and "Fit inside" keeps the whole photo visible with padding instead of cropping.
